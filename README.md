The raster geospatial dataset in this study was acquired and processed using Google Earth Engine (GEE). The study area covers Bogor Regency and Bogor City, West Java Province, Indonesia. The administrative boundary was obtained from the FAO GAUL Level 2 dataset by filtering Indonesia, West Java Province, Bogor Regency, and Bogor City. These administrative units were then merged into a single region of interest (ROI), which served as the spatial boundary for clipping, visualizing, extracting, and exporting all raster datasets.

The raster dataset consists of several environmental factors, including topography, hydrometeorology, vegetation condition, and land use/land cover. The topographic variables were derived from NASADEM, which was used to generate elevation, slope, and aspect layers. Elevation represents terrain height, while slope and aspect were derived using terrain analysis functions in GEE. These variables are important because elevation, slope gradient, and slope orientation strongly influence slope stability and landslide susceptibility.

Hydrometeorological factors were obtained from the CHIRPS Daily rainfall dataset. In this study, rainfall was not used as a single static value, but was processed into several antecedent rainfall accumulation variables, namely rain_1d, rain_3d, rain_7d, rain_14d, and rain_30d. These variables represent accumulated rainfall over 1, 3, 7, 14, and 30 days before the selected analysis date or landslide event date. This approach was applied to capture the influence of antecedent rainfall, which is commonly associated with landslide triggering mechanisms.

Vegetation-related variables were derived from Sentinel-2 Surface Reflectance Harmonized imagery. Sentinel-2 was selected because of its relatively high spatial resolution and its ability to represent surface vegetation conditions. Before calculating vegetation indices, cloud masking was applied using the Scene Classification Layer (SCL) to remove cloud shadows, medium- and high-probability clouds, cirrus, and snow. The Normalized Difference Vegetation Index (NDVI) was then calculated using the near-infrared and red bands. In this study, NDVI was generated for two temporal windows: NDVI 30 days and NDVI 90 days before the analysis date. In addition, NDVI change was calculated as the difference between NDVI 30 days and NDVI 90 days to represent vegetation dynamics, land clearing, vegetation degradation, or other surface-cover changes.

Land use and land cover information was obtained from Dynamic World and ESA WorldCover. Dynamic World was used to generate dynamic land-cover classes and class probability layers, including water, trees, grass, flooded vegetation, crops, shrub and scrub, built area, bare ground, and snow/ice. The Dynamic World land-cover class was derived using the mode value within a 90-day temporal window before the analysis date, while class probabilities were calculated using the mean probability values over the same period. Variables such as built_probability, bare_probability, and trees_probability were used to represent urban expansion, exposed land surfaces, and tree-cover conditions. ESA WorldCover 2021 was also included as a reference land-cover dataset to complement the Dynamic World classification.

All raster variables were clipped to the Bogor Regency and Bogor City ROI and then combined into a single multi-band raster stack. The final raster stack contains multiple predictor bands, including elevation, slope, aspect, rain_1d, rain_3d, rain_7d, rain_14d, rain_30d, ndvi_30d, ndvi_90d, ndvi_change, dynamic_world_lulc, Dynamic World probability layers, and esa_worldcover. Each band represents a different environmental variable, allowing each pixel in the study area to contain multi-dimensional information related to topography, rainfall, vegetation, and land cover.

The resulting raster stack was used as the predictor dataset for landslide susceptibility modeling. The landslide inventory data in vector format was not directly merged as a raster predictor band. Instead, it was used as an event label. Raster values from each predictor band were extracted at landslide and non-landslide sample locations to generate the machine learning training dataset. Therefore, the final dataset consists of two main components: a multi-band raster predictor stack for spatial susceptibility mapping and a training table derived from raster value extraction at labeled sample points.

This dataset acquisition strategy integrates both static and dynamic environmental factors. Static factors include elevation, slope, aspect, and reference land cover, while dynamic factors include antecedent rainfall, NDVI temporal variation, and Dynamic World land-cover probabilities. This approach enables the study to move beyond static landslide susceptibility mapping toward a more advanced spatio-temporal landslide susceptibility and domain awareness framework for Bogor Regency and Bogor City.
